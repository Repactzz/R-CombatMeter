# R-CombatMeter

Damage and healing meter with customizable windows for World of Warcraft: Forever.

## Installation via WowUp

Select WoW Forever, open **Get Addons → Install from URL**, and enter:

`https://github.com/Repactzz/R-CombatMeter`

Enable **Auto Update** to receive new published releases.

## Manual installation

Download the `-forever.zip` asset from [Releases](https://github.com/Repactzz/R-CombatMeter/releases/latest), extract it into `World of Warcraft/_forever_/Interface/AddOns/` and restart the game.

Only approved builds are published as releases. The existing internal addon folder is retained for compatibility with saved settings.
